# WAF 검증 범위 및 미확인 항목

## 확인되지 않은 사항

- `2008–2028` 전체 룰의 실제 설정 내용과 적용 여부
- 각 룰에 대한 공격 재현·차단 성공률
- Apache의 Custom Rule include 관계
- 관리자 대시보드가 읽는 `/var/log/safestay_waf.log` 파일의 실제 생성·갱신 여부
- 웹 애플리케이션에 파일 업로드 기능이 없으므로 업로드 차단 기능의 실제 검증 결과

## 권장 검증 절차 (향후)

1. `apache2ctl -t`와 모듈·룰 로딩 상태 확인
2. 안전한 테스트 요청을 이용한 정상·악성 요청 구분
3. HTTP 상태 코드, 감사 로그 Rule ID, 요청 시간 대조
4. `DetectionOnly`와 `On`의 결과 비교
5. 정상 예약·로그인 흐름에서 오탐 여부 확인
